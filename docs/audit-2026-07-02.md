## 1. Bug: treo ung dung khi Import Excel

**Trieu chung:** bam `Import Excel` -> `Browse...`, chon file `.xlsx` xong thi cua so bi "treo" (khong phan hoi) mot luc, dac biet voi file lon hoac file dang mo san trong Excel.

**Nguyen nhan goc:** `ExcelImportWindow.Browse_Click()` (`src/ANLAbel.App/ExcelImportWindow.xaml.cs`) goi `_viewModel.GetExcelSheetNames(dialog.FileName)` **truc tiep tren UI thread**. Ham nay goi thang `ExcelDataService.GetSheetNames()` (`src/ANLAbel.Data/Excel/ExcelDataService.cs`), mo workbook bang `new XLWorkbook(filePath)` mot cach dong bo — khong `async`, khong `Task.Run`. Voi file lon, file tren network/OneDrive, hoac file dang bi Excel khac giu (lock), thao tac nay co the mat vai giay den vai chuc giay, trong luc do toan bo UI thread bi block nen cua so WPF khong ve lai, giong nhu app "treo"/"khong phan hoi".

Doi chieu: luong `Import Excel` (doc data that) va `Update Excel` (`RefreshExcelDataAsync`) da dung `LoadSheetAsync` boc trong `Task.Run` tu truoc, chi rieng buoc "lay danh sach sheet" khi bam Browse la con sot lai duong dong bo.

**Fix da ap dung (2026-07-02):**
- `Browse_Click` gio boc `GetExcelSheetNames` trong `Task.Run`, disable nut Browse va hien `Mouse.OverrideCursor = Cursors.Wait` trong luc doc file, sau do enable lai / tra cursor du thanh cong hay loi (khoi `finally`).
- Giu nguyen try/catch cho `IOException` (bao ro "dang mo trong Excel, dong lai roi thu lai") va exception khac.
- Xem rule moi so 7 trong `agent.md` de tranh lap lai loi tuong tu o cho khac (vi du neu sau nay them import CSV/khac).

**Chua lam (de xuat neu can sau nay):** them progress indicator/spinner ro rang hon (hien tai chi co wait cursor), va gioi han thoi gian cho (timeout) neu file nam tren network share bi treo do mat ket noi thay vi lock binh thuong.

## 2. Bug: bundle app khong kem sample Excel + template thu vien mat link

**Trieu chung nguoi dung mo ta:** "khi bundle app ko tao kem file excel mau va ko gan link vao template trong thu vien nua".

**Kiem tra thuc te:**
- Co che chinh (`TemplateLibraryService`, `src/ANLAbel.App/TemplateLibrary/TemplateLibraryService.cs`) van hoat dong dung thiet ke: `sample-data.xlsx` va cac `*.anlabel` duoc nhung (`EmbeddedResource`) vao `ANLAbel.App.dll`, luc chay app se giai nen `sample-data.xlsx` ra `%LocalAppData%\ANLAbel\sample-data.xlsx` va `Materialize()` tu sua lai `DatabaseConfig.FilePath` ve duong dan da giai nen (theo ten file `sample-data.xlsx`). Co che nay dung cho 12 template co san (`01_..12_...anlabel`).
- Van de thuc su: 5 template moi duoc them gan day — `20_sample_deltec_cqs_100x70.anlabel`, `21_sample_deltec_data_100x70.anlabel`, `22_sample_data_outer_75x100.anlabel`, `23_sample_jabil_inner_75x100.anlabel`, `24_sample_jabil_outer_110x150.anlabel` — dang bi liet vao `Exclude` trong `ANLAbel.App.csproj` (`EmbeddedResource Include="TemplateLibrary\*.anlabel" Exclude="..."`) nen **khong duoc nhung vao build**, tuc la khong xuat hien trong Template Library sau khi cai/bundle app. Ngoai ra ca 5 file nay co `DatabaseConfig.FilePath`/`SheetName` rong — chua tung duoc gan link Excel, khac voi 12 template kia.
- 5 template nay chua nguyen van du lieu that cua khach hang (ten cong ty "DELTEC", "DELTEC VIETNAM CO.,LTD", "Jabil", "Leflexo Industrial Co., Ltd", ma hang/PO/lot that) o dang text tinh — day rat co the la ly do ai do chu dong loai chung khoi ban dong goi chung (tranh lo du lieu khach hang ra moi may cai app), nhung lam luong "them template moi" bi dang do, khong bao gio hoan thanh viec dong goi.

**Fix da ap dung (2026-07-02), theo lua chon cua nguoi dung (giu lai 5 template nhung bo het ten/ma khach hang, chi de chung chung):**
- Genericize toan bo text tinh la du lieu/ ten khach hang trong 5 file tren (vi du "DELTEC" -> "COMPANY NAME", so PO/Lot/PartNo that -> placeholder chung).
- Gan `BindingExpression` cho cac object gia tri (PartNo, Qty, Lot, PO, MfgDate, Rev, Country...) toi dung cot trong `TemplateLibrary/sample-data.xlsx` (sheet `Data`), giong cach 12 template cu dang lam.
- Gan `DatabaseConfig.FilePath`/`SheetName` cho ca 5 file theo dung pattern cua 12 template kia (de `TemplateLibraryService.Materialize()` tu sua lai duong dan luc chay).
- Bo `Exclude` trong `ANLAbel.App.csproj` de ca 5 file duoc nhung/hien trong Template Library.
- Build lai va xac nhan PASS.

*(Ghi chu: phan nay do mot agent con thuc hien song song, chi tiet tung dong thay doi xem git diff cua 5 file trong `src/ANLAbel.App/TemplateLibrary/`.)*
