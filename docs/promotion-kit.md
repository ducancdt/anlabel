# ANLAbel promotion kit

Use these approved descriptions when sharing ANLAbel. Keep claims factual and link directly to the public repository or latest release.

## Claim boundary

This file is public copy, not release evidence. Publish a version-specific statement only after the owning release checkpoint has a clean commit, build/test output, installer artifact, and any required manual evidence. The current worktree contains an uncommitted implementation wave; do not describe that wave as shipped.

Safe wording is **software-side support** for Excel/CSV binding, barcode rendering, print-plan/preflight at configured DPI, and batch preview. It is not a claim that every Zebra/TSC/Godex/SATO driver, media stock, scanner, verifier, or printer-native command path has been certified. Physical output must be validated locally with the [print calibration checklist](print-calibration.md).

Keep the [license notices](license-notices.md) and GPL-3.0 terms alongside release artifacts. Do not copy Figma design-reference labels or internal version strings into a public release claim; Figma is visual input, not runtime or hardware acceptance.

## One-line description

ANLAbel is an open-source Windows app for designing and printing Excel-driven industrial labels with barcodes, print preflight, and millimeter-accurate output.

## 60-second demo outline

1. Show the blank designer and physical label size.
2. Add a text field, Code 128 barcode, and QR Code.
3. Import a generic Excel sheet and bind two columns.
4. Switch between two preview records.
5. Open Print Preview and point out preflight checks and printer DPI.
6. End on the GitHub repository and Releases link.

Use synthetic product data in demonstrations. Never show customer names, real part numbers, production workbooks, internal paths, credentials, or proprietary templates.
